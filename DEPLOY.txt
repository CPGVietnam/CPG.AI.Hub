STATIC HOST DEPLOYMENT

1. Upload the complete contents of this project directory.
2. Keep the assets/ and src/ folder structure unchanged.
3. Configure index.html as the default document.
4. No build command is required.

Compatible targets include GitHub Pages, Cloudflare Pages, Netlify, Vercel,
IIS, and other static web hosts.

For Cloudflare Pages, use the project directory as the output directory and
leave the build command empty.
